## Maryam Shahverdi's Portfolio 🌐

My personal portfolio website — a multi-page site built with plain HTML, CSS, and JavaScript, showcasing my projects and skills as a backend developer.

## 🔗 Live site

**[maryamshahverdi.github.io/portfolio-maryam-shahverdi](https://maryamshahverdi.github.io/portfolio-maryam-shahverdi/)**

## 📄 Pages

- **Home** (`index.html`) — introduction, profile photo, and a quick look at my skills
- **About** (`about.html`) — a short bio and the full list of skills
- **Projects** (`projects.html`) — a showcase of my projects, each linking directly to its GitHub repository
- **Contact** (`contact.html`) — my email, GitHub profile, and a simple contact form

## 🛠️ Built with

- HTML5
- CSS3 (custom, no framework) — responsive layout with a mobile navigation menu
- Vanilla JavaScript — mobile menu toggle and a scroll-to-top button

## 📁 Project structure

portfolio-website/

## 🚀 Running locally

Just open `index.html` in your browser — no build step or server required.
